## Build Your Own PyTorch

A project-based curriculum that teaches how modern deep learning frameworks work by rebuilding PyTorch from scratch. Starting with scalar backpropagation and reverse-mode automatic differentiation, learners progressively implement tensors, neural network layers, optimizers, CNNs, attention mechanisms, Transformers, Vision Transformers, and eventually a small but practical PyTorch-like framework.

The goal is to develop a deep understanding of autodiff, tensor operations, and neural network training by implementing every component manually rather than relying on existing libraries. Each chapter combines theory with hands-on projects, gradually transforming a simple computational graph into a complete deep learning framework.
